# Security Policy

## Supported Versions
This repository is a multi-site Drupal workspace with multiple active components.
Security fixes will be released in the main branch.

## Reporting a Vulnerability
Please use GitHub Security Advisories to report vulnerabilities privately:
- Go to the repository Security tab and select "Report a vulnerability."

If you cannot use GitHub Security Advisories, open a GitHub issue with the
label "security" and include only high-level details. Maintainers will respond
with a private channel for sensitive information.

## Response Process
- Triage within 7 days
- Fix plan documented in the advisory or private channel
- Disclosure coordinated after a fix is available
