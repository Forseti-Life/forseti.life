# Contributing to Forseti.life

Thanks for considering a contribution. This repository is a full-stack, multi-site Drupal workspace with a strict architecture-first process.

## Ground Rules
- Be respectful and constructive. See CODE_OF_CONDUCT.md.
- No secrets in commits. Do not add API keys, credentials, or private data.
- No quick fixes. Diagnose root causes and document findings.
- Update documentation when behavior or architecture changes.

## How to Contribute
1. Open an issue describing the change or improvement.
2. Read the relevant ARCHITECTURE.md and README.md before coding.
3. Update architecture documentation first, then implement.
4. Keep changes focused and well scoped.
5. Open a pull request and describe the reasoning and validation steps.

## Development Process
- Architecture-first workflow is mandatory.
- Use Drupal-native patterns whenever possible.
- Avoid custom code when standard Drupal features solve the problem.

## Documentation Requirements
- Update README.md and architecture docs when behavior changes.
- Do not create Summary.md or status files for tracking.

## Security
If you find a security issue, follow SECURITY.md.
